# Preview（マークダウン HTML プレビュー & コメント反映）スキル

マークダウンを書いた人（Claude を含む）とレビューする人（ユーザー）の間の FB ループを回す。
プレビューはレンダリング済みの読みやすい HTML で、ユーザーは本文を選択してその場にコメントを残す。
コメントは **HTML ファイル自身**（`embedded-comments` JSON 領域）に保存されるため、
Claude はそのファイルを読むだけでレビュー結果を回収できる。

付属ファイル（この SKILL.md と同じディレクトリ、実体は `~/.ai_agent/skills/ore-preview/`）:

- `scripts/build_preview.py` — md → コメント可能な HTML を生成（依存ライブラリなし）
- `scripts/read_comments.py` — HTML からコメント JSON を取り出す
- `assets/template.html` — marked.js とコメント機能を同梱したテンプレート（直接編集しない限り読む必要はない）

---

## フェーズ1: プレビューを生成して開く

1. 対象のマークダウンファイルを特定する。ファイルがまだ無い文章（会話中の下書きなど）は、
   先にマークダウンとして保存してから使う。
2. 出力先はプロジェクトルート直下の `.ai_workspace/tmp/{yyyymmdd-HHMMSS}/` とする
   （CLAUDE.md の一時ファイル規約に従う。プレビューはコメントの保存先を兼ねるので、
   レビューが終わるまで消さない）。
3. 生成して開く:

   ```bash
   python3 ~/.ai_agent/skills/ore-preview/scripts/build_preview.py \
     <input.md> <出力先>/preview-<basename>.html --title "<文書タイトル>"
   open <出力先>/preview-<basename>.html
   ```

4. 開いたら、ユーザーに使い方を短く案内する:
   - 本文を選択すると「コメント追加」ボタンが出る。書き込むとその箇所がハイライトされる
   - **初回のコメント投稿時だけファイル選択ダイアログが開く。表示中のプレビュー HTML
     自身を選択**すると、以後は自動でファイルに保存される（ヘッダーに「保存済み ✓」と出る）
   - Chrome / Edge 推奨。Safari / Firefox はファイル書き込み API が無いため、
     コメント JSON のダウンロードにフォールバックする（その場合は保存された
     `*.comments.json` のパスを教えてもらう）
   - レビューが終わったら「コメント反映して」と言えばフェーズ2に進む

案内したらユーザーのレビューを待つ。先回りして反映を始めない。

## フェーズ2: コメントを読み取って反映する

「コメント反映して」等で起動する。

1. コメントを読み取る（HTML はユーザー操作で書き換わっているので、必ず反映の直前に読む）:

   ```bash
   python3 ~/.ai_agent/skills/ore-preview/scripts/read_comments.py <preview.html>
   ```

   出力は `{"source": "<元 md のパス>", "comments": [...]}`。各コメントは
   `quote`（選択された本文）・`body`（コメント内容）・`startOffset`（文書内の出現順）を持つ。

2. 各コメントの `quote` を元マークダウン内で検索して該当箇所を特定する。
   `quote` はレンダリング後のテキストなので、記法（`**` やリンク記法）を挟んで
   完全一致しないことがある。その場合は前後の文や `startOffset` の順序を手がかりに探す。

3. コメントを2つに分けてから動く:
   - **そのまま反映できるもの** — 修正指示が明確なもの。まとめて元マークダウンに反映する
   - **判断が必要なもの** — 方針の選択を含むもの、意図が読み取れないもの。
     番号付きで提示してユーザーの判断を仰ぐ

4. 反映が終わったら、コメントごとに「どう対応したか」を1行ずつ報告し、
   プレビューを**再生成して開き直す**（フェーズ1と同じ手順、同じ出力パスに上書きでよい）。
   再生成するとコメントはリセットされるので、必ず反映が終わってから行う。
   ユーザーは新しいプレビューで再レビューでき、ループが回る。

## 注意

- プレビュー HTML はコメントの保存先を兼ねる。**反映前に再生成するとコメントが消える**
- 元マークダウンが Claude 管理外で編集されている可能性があるときは、反映前に読み直す
- コメントが 0 件のときは「コメントは見つからなかった」と伝え、
  初回保存ダイアログでプレビュー HTML 自身を選択したかを確認する（別ファイルに
  保存されているとここに現れない）
