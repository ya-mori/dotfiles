# ore-ai-review

**Copilot + Codex + Claude トリプル AI レビュースキル**

Copilot CLI・Codex CLI・Claude サブエージェント（9視点）を並列実行し、
3エージェントのレビュー結果を並べて表示します。
各エージェントは批判的な視点でレビューを行い、疑わしい箇所や潜在的な問題を積極的に洗い出します。

---

## 設定

- `MAX_DIFF_LINES`: 2000（この行数を超えた場合に警告を表示）

---

## 実行手順

### Phase 0: モード判定

ユーザーの入力に `--diff` が含まれているかどうかで動作モードを決定する。

| 条件 | モード | diff コマンド |
|------|--------|--------------|
| `--diff` あり、または「未コミット変更をレビュー」「git diff でレビュー」 | **未コミット変更モード** | `git diff HEAD` |
| それ以外（デフォルト） | **ブランチ差分モード** | `git diff {base_branch}...HEAD` |

**ブランチ差分モードの場合のみ：ベースブランチを自動検出する**

以下の順に存在を確認し、最初に見つかったものを `base_branch` として使用する：

1. `git rev-parse --verify develop` → 存在すれば `develop`
2. `git rev-parse --verify main` → 存在すれば `main`
3. `git rev-parse --verify master` → 存在すれば `master`

いずれも存在しない場合は以下を表示して終了する：
```
ベースブランチ（develop / main / master）が見つかりません。
--diff オプションを使用するか、リポジトリのブランチ構成を確認してください。
```

現在のブランチが `base_branch` と同じ場合は以下を表示して終了する：
```
現在のブランチは {base_branch} です。別のブランチで実行してください。
--diff オプションを使用すると未コミット変更のみをレビューできます。
```

---

### 事前チェック

1. `which copilot` を実行し、存在しない場合は以下を表示する（続行）：
   ```
   ⚠️ copilot コマンドが見つかりません。
   インストール: https://docs.github.com/copilot/how-tos/copilot-cli
   ```

2. `which codex` を実行し、存在しない場合は以下を表示する（続行）：
   ```
   ⚠️ codex コマンドが見つかりません。
   インストール: npm install -g @openai/codex
   ```

3. モードに応じた diff コマンドを実行し、空の場合は以下を表示して終了する：

   **未コミット変更モード** (`git diff HEAD` が空の場合)：
   ```
   レビュー対象の未コミット変更が見つかりませんでした（git diff HEAD が空です）。

   ヒント:
   - ステージ済み変更がある場合: git add した変更は git diff HEAD に含まれます
   - git status で現在の状態を確認してください
   ```

   **ブランチ差分モード** (`git diff {base_branch}...HEAD` が空の場合)：
   ```
   {base_branch} との差分がありません。
   コミットを積んでから実行してください。
   ```

   git リポジトリ外でエラーになった場合：
   ```
   git リポジトリ内で実行してください。
   ```

### Phase 1: 情報収集

モードに応じたコマンドを実行してコンテキストを収集する：

| 項目 | ブランチ差分モード | 未コミット変更モード |
|------|-------------------|-------------------|
| diff | `git diff {base_branch}...HEAD` | `git diff HEAD` |
| stat | `git diff {base_branch}...HEAD --stat` | `git diff HEAD --stat` |
| log  | `git log {base_branch}..HEAD --oneline` | `git log --oneline -5` |

結果をそれぞれ `diff_full`、`diff_stat`、`git_log` として保持する。

4. `git status --short` — 現在のステータス（共通）

また、**現在の会話コンテキストから**以下を要約する（Bash は使わず Claude が判断）：
- **実装の目的**: 今回の実装で何を・なぜ実装したか（不明な場合は「不明」と記載）
- **設計上の決定**: 採用したアプローチと理由（不明な場合は「不明」と記載）

`diff_full` の行数が `MAX_DIFF_LINES` を超える場合は以下を表示してから処理を継続する：
```
⚠️ 変更量が多いため（{行数}行）、レビューに時間がかかる場合があります。
```

---

### Phase 2: 並列エージェント実行

**単一メッセージで以下の3つのサブエージェントを同時起動する（並列実行）。**

各エージェントには Phase 1 で収集したコンテキストをすべて渡す。

---

#### エージェント A: Copilot レビュー（copilot コマンドが存在する場合のみ起動）

以下のコマンドを Bash で実行する：

```bash
copilot -p "以下の変更を批判的な視点でコードレビューしてください。
表面的な確認で済ませず、疑わしい箇所や潜在的な問題を積極的に洗い出してください。安易に承認せず、少しでも懸念があれば具体的に指摘してください。
git diff だけでなく、変更の意図・設計の妥当性・リポジトリ全体との整合性も確認してください。
問題点は [Critical] / [Important] / [Minor] で分類し、日本語で報告してください。

=== 実装の目的 ===
{実装の目的}

=== 設計上の決定 ===
{設計上の決定}

=== 変更ファイル一覧 ===
{diff_stat}

=== 最近のコミット履歴 ===
{git_log}

=== 差分 ===
{diff_full}

最後に必ず以下のいずれかを出力してください（他の文言は不要）：
VERDICT: APPROVED
VERDICT: REJECTED" \
  --allow-tool='shell(git:*)' \
  --allow-tool='read' \
  --plain-diff
```

返却形式：
```
COPILOT_OUTPUT: {copilot コマンドの出力全文}
COPILOT_VERDICT: {APPROVED / REJECTED / 不明}
```

VERDICT の判定方法：
- 出力に `VERDICT: APPROVED` が含まれる → `APPROVED`
- 出力に `VERDICT: REJECTED` が含まれる → `REJECTED`
- どちらも含まれない → `不明`

## エッジケース

| ケース | 対応 |
|--------|------|
| diff が空（未コミット変更モード） | 「未コミット変更が見つかりません」を表示して即終了 |
| diff が空（ブランチ差分モード） | 「{base_branch} との差分がありません」を表示して即終了 |
| git リポジトリ外 | エラーメッセージを表示して即終了 |
| ベースブランチが存在しない | 案内メッセージを表示して即終了 |
| 現在ブランチがベースブランチと同じ | 案内メッセージを表示して即終了 |
| copilot コマンドなし | インストール案内を表示し、他エージェントで続行 |
| codex コマンドなし | インストール案内を表示し、他エージェントで続行 |
| diff が 2000 行超 | 冒頭に警告を表示しつつ処理継続 |
| エージェントがタイムアウト・失敗 | 該当側を「取得失敗のためスキップ」として表示し、残りは継続 |
| サブエージェントが失敗・タイムアウト | 該当視点を「（取得失敗のためスキップ）」として表示し、残りは継続 |
