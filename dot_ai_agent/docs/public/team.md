# チーム・連絡先

チームメンバーと Slack チャンネルの一覧。
**実データは同名の `docs/private/team.md` にある**（実名・チャンネル名を含むため）。
このファイルは列の意味と使い方だけを持つ。

---

## 使いどころ

| 場面 | 見る列 |
|---|---|
| 対外メッセージの宛先を判断する | メンバーの **距離感**。`他チーム` / `社外` なら内部用語を避ける（`ore-message` 参照） |
| 「誰に聞くか」を判断する | メンバーの **担当領域**。候補が複数なら決め打ちせず確認する |
| 投稿先チャンネルを選ぶ | チャンネルの **用途** と **参加範囲**。`社外含む` なら内部用語を避ける |

---

## 列の定義

### メンバー

| 列 | 内容 |
|---|---|
| 名前 | 会話で使う呼称 |
| 担当領域 | 何を聞ける人か |
| 距離感 | `同チーム` / `他チーム` / `社外`。**語彙と丁寧さはこれで決まる** |
| Slack | メンション用の ID |

### Slack チャンネル

| 列 | 内容 |
|---|---|
| チャンネル | `#` 付きの名前 |
| 用途 | 何を投稿する場か |
| 参加範囲 | `同チーム` / `部署横断` / `社外含む` |
| 作法 | スレッド運用・メンションの習慣など、外すと失礼になる暗黙のルール |

---

## 運用

- **列は増やさない。** 増やすときは1つ削る（埋められない列は結局書かれなくなる）
- private 側が無い環境では、このファイルだけで「そういう情報がある」と分かればよい
