# Plan Setup

**タスクファイルセットアップスキル**

このスキルは、タスクの種類に応じた専用のマークダウンファイルを作成し、作業開始の準備を行います。

---

## 動作フロー

### 1. タスクタイプの決定

コマンド名またはユーザーの発言からタスクタイプを判定する：

- `/planpdca` が呼ばれた → `pdca` タイプに固定
- `/planprompt` が呼ばれた → `prompt` タイプに固定
- `/ore-plan-setup`（引数なし）または曖昧な発言 → ユーザーに以下の3択を提示：

```
タスクの種類を選択してください：

1. **impl（コード実装）**
   コード実装タスク用。設計・ステップ・確認方法を整理するテンプレートを使用。

2. **pdca（PDCAサイクル）**
   PDCAサイクルに基づくタスク管理用。対話的な計画・実行・評価・改善を記録。

3. **prompt（プロンプト作成）**
   プロンプトエンジニアリング用。目的とプロンプト内容を記述するシンプルな構成。
```

### 2. 目的の確認

「どのようなタスクを開始しますか？目的を教えてください」と質問し、ユーザーの回答を記録する。

### 3. タスク名の生成

目的をもとに適切なタスク名を自動生成する：
- 英数字とハイフンのみ使用（スペースはハイフンに変換）
- 例: "APIエンドポイントの追加" → `api-endpoint-addition`

### 4. ディレクトリの作成

```bash
DATE=$(date +%Y-%m-%d)
mkdir -p .ai_workspace/claude/tasks/${DATE}-{タスク名}/
```

### 5. ファイル作成（タイプ別）

| タイプ | テンプレート | 出力ファイル名 | 完了メッセージ |
|--------|-------------|--------------|--------------|
| `impl` | `~/.claude/skills/ore-plan-setup/templates/codeplan-template.md` | `task_plan.md` | 「タスクの設計を進めてください。」 |
| `pdca` | `~/.claude/skills/ore-plan-setup/templates/taskpdca-template.md` | `index.md` | 「PDCAサイクルに基づいてタスクを進めてください。」 |
| `prompt` | なし（下記インライン定義を使用） | `prompt.md` | 「タスクの設計を進めてください。」 |

#### `impl` / `pdca` タイプの処理

テンプレートファイルを読み込み、以下の変数を置換して出力ファイルに保存する：
- `{タスク名}` → 生成したタスク名
- `{YYYY-MM-DD HH:MM}` → `$(date +"%Y-%m-%d %H:%M")` の出力

#### `prompt` タイプのファイル内容

テンプレートファイルなし。以下の内容でファイルを作成する（変数を実際の値に置換）：

```markdown
# {タスク名}

作成日時: {YYYY-MM-DD HH:MM}

## 目的

{ユーザーが入力した目的}

## プロンプト

<!-- ここにプロンプトを記述してください -->
```

### 6. 完了通知

以下を表示して完了する：
- 作成したファイルの保存先パス
- タイプに応じた完了メッセージ
